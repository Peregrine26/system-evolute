# CrossDesk C++/Qt 桌面功能

本分支用 C++17/Qt 实现桌面格子，以 DeskBox 固定提交 fb6e1c4aaf811a5cc8b0748ced4a0639631176cb 为功能参考。不接入 C#/WinUI 应用或 Rust 模块；QuickLook、Everything 等外部程序集成已排除，不分发 Everything SDK。

## 构建与运行

本机隔离工具链：Qt 6.8.3、MinGW GCC 13.1、CMake、Ninja，位于 `%USERPROFILE%\.codex\tools\crossdesk`。在项目根目录运行：

```powershell
.\scripts\build.ps1 -DesktopTests
. .\scripts\dev-env.ps1
.\build-desktop\crossdesk.exe
```

`-DesktopTests` 需要已登录的交互式 Windows 桌面；省略该参数仅运行非交互测试。中文项目路径通过工具链目录下的 ASCII 目录联接构建，不移动工作区。当前构建目录需要会话中的 Qt/MinGW DLL 路径，尚不是安装包。

默认数据目录 `%LOCALAPPDATA%\CrossDesk`；`--data-dir <目录>` 可创建独立工作区，同一工作区仅一个实例。`--smoke` 使用临时数据、禁用联网并自动退出。

正常启动进入应用窗口总览；`Ctrl+Alt+M` 打开/收起总览。桌面工具从总览或托盘进入，也可用 `--desktop-tools` 直接打开。交互取舍见 [CrossDesk 交互取舍](interaction-decisions.md)。

## 本次保留的边界

- 已统一总览主入口、预览确认、关闭/退出、格子显示和备份策略。桌面层接管、额外全局手势、自动搬文件、完整多屏组合布局、WebDAV 和自动更新安装继续不启用，保留现有的显式操作方式。
- 有托盘时主面板关闭默认后台运行，显式退出会先保存；可在偏好设置取消后台运行。F7 临时收起启用的格子，单独关闭的格子仅由明确重开操作恢复。
- 格子断屏临时适配保留原位置记录，重新接回可恢复；主动拖动/缩放才更新归属。屏幕适配不重建编辑器。
- 不自动隐藏、恢复或排列外部应用；格子分组不等同于应用 Workspace。
- 移动使用同卷原子重命名；跨卷移动报错并保留来源，可先复制并核对。复制成功不会自动删除来源。
- 本地搜索不维护外部索引：默认扫描映射目录及桌面/文档/下载，可增加目录；每次最多检查 250000 项、显示最多 2000 项，不是瞬时全盘索引。
- 天气需要网络；没有接入未公开的 MSN 接口，未复制原项目全部图标/皮肤资产和十二种语言资源。
- 音乐需要播放器公开 Windows 媒体会话及控制能力。本机只读验证没有活动会话，已验证空会话回退；真实曲目/封面/定位/循环仍需有支持的播放器时交互验收。
- 提醒在运行时每 30 秒检查，启动也检查已到期任务；同次运行按任务及截止时间去重，退出期间不唤醒系统。
- 便携备份仅包含被引用的托管附件，合计上限 16 MiB、JSON 上限 32 MiB；映射原文件、关联外部原附件及本地背景图片不打包。失效的正文文件链接保留为文本；明确登记的托管附件缺失时导出失败。恢复不覆盖本机设置，也不导入旧文件移动撤销记录。
- Windows x64 已本机构建；ARM64、其他平台及不同显示器/DPI 组合尚未实机验收。
