# CrossDesk C++/Qt 桌面功能

本分支在现有 C++17/Qt 应用中实现桌面格子。DeskBox 1.5.8 固定提交
`fb6e1c4aaf811a5cc8b0748ced4a0639631176cb` 仅作为功能参考；未接入其
C#/WinUI 应用或 Rust 模块。实际随程序分发的 Everything C SDK DLL
及其 MIT 许可见 `third_party/everything/`。

## 构建与启动

本机隔离工具链为 Qt 6.8.3、MinGW GCC 13.1、CMake 和 Ninja，位置默认为
`%USERPROFILE%\.codex\tools\crossdesk`。在项目根目录执行：

```powershell
.\scripts\build.ps1 -DesktopTests
. .\scripts\dev-env.ps1
.\build-desktop\crossdesk.exe
```

`-DesktopTests` 会创建测试窗口，需要已登录的交互式 Windows 桌面；省略该参数
只运行可自动执行的非交互测试。含中文的项目路径通过工具链目录下的 ASCII
目录联接构建，不移动工作区。运行程序需要当前会话加载上述 Qt/MinGW DLL 路径；
此构建目录尚不是可分发安装包。

默认数据目录为 `%LOCALAPPDATA%\CrossDesk`。可用
`--data-dir <目录>` 创建独立工作区；同一工作区只允许一个实例，第二次启动会唤回
主窗口。`--smoke` 使用临时数据、禁用联网并自动退出，不读写正式数据。

## 当前交付与验收

| 功能 | 当前行为 |
| --- | --- |
| 普通应用窗口清单 | 用进程 ID 排除当前 CrossDesk 的全部窗口；不按标题或进程名称排除。Explorer、Windows 设置及其他应用仍按原扫描规则保留。 |
| 窗口总览 | 刷新、激活、两个 DWM 实时预览、等宽及 60:40 布局，逐窗显示执行结果。 |
| 文件格子 | 映射已有文件夹、浏览子目录、切换图标/列表、排序及隐藏文件开关；浏览不会改写映射根目录。支持本地文件拖放复制/移动、粘贴、重命名、回收站与系统菜单。 |
| 文件整理 | 预览待移动项，逐项选择分类目录或已有格子，确认后移动；目标重名会报错并保留来源，可撤销上次单个文件移动。 |
| 待办 | 增删改、完成状态、截止时间、到期提醒、每日/每周重复、筛选、备注、附件、转随记。 |
| 随记 | Markdown 编辑与预览、自动保存、导出、附件、转待办。 |
| 搜索 | 搜索待办、随记及文件；优先使用 Everything 索引，不可用时扫描映射文件夹。 |
| 时光、天气、音乐 | 日期时间及农历月日；Open-Meteo 城市天气与多日预报；系统媒体按键与系统音量。 |
| 格子与设置 | 分组标签、收起及悬停展开、置顶、明暗主题、透明度、托盘、自定义全局快捷键、显式选择的开机启动。 |
| 本地保存与备份 | 原子配置保存、上一版恢复、配置及托管附件导出/恢复。 |

提醒在程序运行时每 30 秒检查一次，启动后也会检查已到期任务；同一次运行中按
任务和截止时间去重。通知通过系统托盘发送，无托盘时使用非模态窗口。程序退出
期间不会唤醒系统发送通知，系统通知设置也会影响展示。

文件复制会校验内容，拒绝覆盖重名目标、复制到自身及符号链接来源。跨卷目录
移动可能失败并提示；大文件传输目前同步执行，可能阻塞界面。整理只在用户确认后
执行，不自动整理桌面。备份包含数据目录中的托管附件，原始附件合计最多 16 MiB、
JSON 最多 32 MiB；映射文件夹的原始文件不打包。

| 范围 | 尚未实现或仅有基础版的部分 |

| 待办与随记 | 批量操作、颜色标记、待办 Markdown 备注预览、可调双栏详情、随记固定/纸张样式/专注模式、完整附件管理。 |
| 搜索 | 应用和系统设置搜索、历史/收藏、高级筛选与可排序详细列、多选批量操作、Everything 程序检测/启动与设置页。 |
| 天气与时光 | MSN 数据源和回退、逐小时天气、天气皮肤与离线缓存、节气节日、背景轮播。 |
| 音乐 | 媒体会话选择、曲目信息/封面、播放进度拖动、播放模式与唱片布局。 |
| 桌面与外观 | Explorer 桌面层挂接、临时唤起层、胶囊栏及摘要隐私、Mica/Acrylic 材质、全景背景、独立图标/字体/配色及多语言。当前格子为独立 Qt 工具窗口。 |
| 显示器与交互 | 按显示器组合记忆布局、拔插后恢复原位、跨屏比例迁移、排列预览、吸附与整体拖动；双击 Ctrl/桌面空白及单独 Win 键等唤起手势。 |
| 发布与运维 | WebDAV 定时备份及合并恢复、诊断包、自动更新、安装/卸载包、完整缓存与性能策略；ARM64 尚未实机验证。 |

## 测试记录

2026-11-24 在本机 Windows 交互会话构建并通过 10 项 CTest 测试。重点检查：

- 标题任意的同进程窗口全部排除，外部窗口即使标题为 CrossDesk 也保留。
- 真实工作台、文件/待办格子、设置/弹窗和窗口总览共 6 个自有可见窗口均被排除。
- 实际 Qt 文件模型的拖放、重名保护、浏览与重新映射，以及整理预览确认后的移动。
- 实际待办界面的创建、编辑截止时间/提醒、完成/重复和删除；存储提醒判断覆盖时间边界与去重。
- 随记切换/关闭保存、配置恢复、附件备份校验，以及原有 Win32、布局、Qt 生命周期和 DWM 测试。

CI 编译交互测试但不执行这些桌面操作；Qt 非交互测试使用 offscreen 后端。
