# CrossDesk 课程简化版

> 2026-10-20 起作为本学期的需求基线。旧的 `project-overview.md`、`implementation-details.md` 和三份 AI 交接中的多 Workspace 方案保留为扩展参考；与本文冲突时以本文为准。

## 一句话介绍

CrossDesk 是一个 **Windows 桌面窗口整理小工具**：用 Qt 列出当前打开的普通窗口，允许用户选中窗口进行定位，或选中两个窗口让它们左右排列；总览和布局预览之间有流畅的切换动画。

借鉴 Mission Control 的“看见所有窗口再选择”的思路。项目重点是学会把 Qt 界面、C++ 逻辑和 Win32 API 分开，并能在答辩时讲清楚每一层。

## 必做功能

| 编号 | 功能 | 完成标准 |
| --- | --- | --- |
| M1 | 扫描和刷新窗口 | 点击“刷新”后，列表显示当前可见、有标题的普通顶层窗口，包括文件资源管理器、Windows 设置等可见系统应用窗口；至少展示标题和进程名。关闭窗口后再次刷新，旧条目消失。 |
| M2 | 定位一个窗口 | 选中列表中的窗口并点击“定位”；程序尝试把它切到前台。目标已关闭或 Windows 拒绝置前时，显示失败提示，不让程序崩溃。 |
| M3 | 左右排列两个窗口 | 选中两个普通窗口，选择等宽或左侧主窗口（60/40）布局，进入预览并点击“确认排列”；在单显示器的可用区域内左右放置，保留固定间距。操作失败时指出对应窗口；刷新后能看到最新位置。 |
| M4 | 界面切换动画 | 打开/收起总览，以及总览/左右布局预览之间切换时，有简短平滑的 Qt 过渡。预览显示两个已选窗口的标题和左右位置；收起后仍能重新打开总览。动画中按钮不会重复触发操作，操作失败时提示仍清楚可见。 |
| M5 | 基本快捷键 | 全局 `Ctrl+Alt+M` 打开/收起总览；应用内 `Ctrl+R` 刷新、`Enter` 定位单个选中窗口、`Ctrl+Enter` 确认两窗排列、`Esc` 从预览返回总览。快捷键与按钮走同一命令路径；全局组合被占用时显示提示，按钮仍可操作。 |
| M6 | 实时窗口缩略图 | 总览中至少同时显示两个普通窗口的持续更新预览；演示时改变来源窗口内容，预览随之变化。使用 Windows DWM 缩略图；关闭/刷新窗口或退出时释放注册。单个来源不可预览时显示标题/进程名占位，其余预览和列表仍可用。 |

课程版只支持 **Windows 10/11 当前登录桌面上的可见顶层窗口**，以单显示器为验收环境。“一些系统窗口”具体指文件资源管理器、Windows 设置等能正常枚举的应用窗口：可列出和尝试定位，移动/预览按实际能力处理，不保证每个系统窗口都支持。任务栏、桌面背景、开始菜单、UAC/安全桌面和受保护窗口不作为管理目标；权限更高、全屏或拒绝调整大小的窗口可提示“不支持”。界面提供列表、实时预览、布局预览和明确的按钮，重点是操作真实有效且过渡自然。

## 本学期不做

- 多 Workspace、自动隐藏/恢复窗口、模拟原生虚拟桌面。
- Linux X11/Wayland 后端、跨平台验收。
- 任意数量窗口的实时缩略图墙、复杂的系统窗口动画、托盘、快捷键自定义/配置保存、开机自启。
- 任意数量窗口的复杂自动布局、多显示器、高 DPI 精细适配。
- 不为复用而移植 DeskBox 的整套实现。优先复用本仓库已有代码；外部代码确实适用时再引入，并遵守课程规则和原许可证。不要求在每段代码旁重复标注出处，但直接复制时须保留许可证要求的声明。

现有仓库中的隐藏/显示等 Win32 实验可以保留，但课程版 UI 不调用它们。这样不会因隐藏窗口后无法找回，影响演示或用户桌面。

**动画边界**：M4 只动画化 CrossDesk 自己的 Qt 界面，不伪称真实应用窗口已完成切换。外部窗口移动、置前仍按 Win32 操作结果报告。先实现静态可用界面，再加过渡；动画时长以现场手感调整，不把复杂效果当作正确性的前提。

## 最小架构

```text
Qt 总览、DWM 预览区域和切换动画（C）
          ↓
窗口筛选、选择校验和两窗布局（B）
          ↓
统一 WindowApiAdapter 接口（A 与 B 约定）
          ↓
Win32/DWM 实现：扫描、置前、移动/缩放、缩略图（A）
```

A 的 Win32 后端负责查询和请求系统操作，集成层负责调用 B 的计算结果并逐窗报告操作结果；A 另负责 DWM 缩略图的注册、更新和注销。B 用普通 C++ 数据处理列表和布局，校验 C 传来的窗口标识，不直接调用平台操作，也不排除所有系统应用。C 负责列表、模式选择、使用 B 的矩形展示布局预览、为 DWM 提供预览位置和显示操作反馈。B/C 的代码不包含 `windows.h`。屏幕可用区域应由 A 以与窗口位置相同的坐标系提供给 B；不要在 B 中写死分辨率。

## 三人分工

| 成员 | 本学期只负责这些 | 可展示的个人成果 |
| --- | --- | --- |
| A：主负责人 | 验证 Windows 扫描器；完成置前、设置位置/大小、获取工作区接口；注册全局总览快捷键；实现 DWM 缩略图注册、定位、清理及 Windows 集成。 | 能演示文件资源管理器等系统应用的扫描、两个实时预览、窗口控制与全局快捷键；说明失败条件。 |
| B：核心逻辑 | 窗口筛选、选择校验、等宽/60:40 两种布局计算及失败结果；写不依赖真实桌面的单元测试。 | 用假窗口验证系统应用不被按进程名一律排除、失效选择和布局边界；鼠标与快捷键共用规则。 |
| C：Qt 界面 | 总览、两种布局预览、DWM 预览区域、按钮与应用内快捷键、失败占位及两段界面动画；对接 A 的全局事件和缩略图结果。 | 用鼠标或键盘走通刷新、定位、排列；同时展示两个实时预览，单个预览失败仍可操作。 |

A 仍是集成负责人，但不要求一人实现三个人的模块。每人只需讲清自己负责的 API/逻辑，再了解整条调用路径。

## 四个完成节点

1. **构建成功**：Windows 上能运行现有 `crossdesk` 和 `crossdesk_window_scanner`，记录 Qt、CMake、编译器版本。
2. **各模块独立通过**：A 的 Win32 实验能扫描和调整自有测试窗口；B 的假数据布局测试通过；C 的假数据总览与布局预览可以切换。
3. **集成 M1、M2**：Qt 显示真实窗口，刷新与定位一个窗口可演示，失效窗口有提示。
4. **集成 M3、M4、M5、M6 并冻结**：两窗左右排列、两段 Qt 过渡、快捷键和两个实时预览可演示；三位组员在同一台 Windows 电脑按演示脚本走通；之后只修错误、不加功能。

建议演示：打开记事本、文件资源管理器和 Windows 设置；按 `Ctrl+Alt+M` 打开总览，展示记事本与文件资源管理器两个实时预览，改变记事本内容并观察预览更新；按 `Ctrl+R` 刷新，选中记事本并按 `Enter` 定位；选中记事本和文件资源管理器，在预览中切换等宽/60:40，按 `Ctrl+Enter` 确认排列；展示设置窗口可列出、不可控制时有反馈；关闭记事本再刷新，展示列表更新。答辩时 A 讲 Win32、DWM 和全局快捷键，B 讲筛选/布局边界，C 讲 Qt 交互、预览区域和动画状态。
