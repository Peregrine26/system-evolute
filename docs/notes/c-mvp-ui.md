## 五个必须能讲清的点

**1. 界面为什么不自己存"窗口在哪"？**
界面拿到的是一份快照（`QVector<WindowItem>`），每次刷新整份替换。窗口位置、能不能操作，都由服务说了算。界面只额外记一件服务不关心的事：**哪个窗口上次失败了、失败原因是什么**（`m_failures`）。这不构成"第二份真相"，因为它只在收到结果信号时写入。

**2. 为什么命令不返回 bool？**
`placeWindow()` 是 `void`，结果走 `operationFinished(OperationResult)`。因为真实实现是系统调用：`SetWindowPos` 返回 true 只代表"调用发出了"，窗口可能被系统拒绝。两个窗口里失败一个，只有逐窗回报才说得清是哪一个——这就是 `OperationResult.window` 的用途。

**3. 最多两个窗口，勾第三个为什么是"替换"而不是"不响应"？**
`onItemChanged` 里判断 `m_checked.size() >= 2`，取最早的那个取消勾选，并在状态栏说明。理由：点了没反应，用户会以为程序卡了；静默拒绝比明确替换更糟。

**4. 换页动画期间为什么要禁用按钮？**
`fadeToPage()` 里设 `m_animating = true` 并禁用四个按钮。否则连点两下"确认排列"会发两轮命令；第一轮还没回来，第二轮又发出去，最后状态栏显示的是哪一轮都说不清。这是 M4 的硬要求："动画中按钮不会重复触发操作"。

**5. 为什么 Enter 没有单独注册 QShortcut？**
`QListWidget` 自己会把回车解释成"激活当前项"并发出 `itemActivated`。再注册一个 `QShortcut(Return)` 会和它抢同一个按键，出现一次回车发两条命令。所以 Enter 走 `itemActivated`，其余三个键走 `QShortcut`。

## 失败路径（老师最爱问）

| 场景 | 界面怎么表现 |
| --- | --- |
| 定位被系统拒绝 | 状态栏红字写明原因，该行末尾加 `! 原因` |
| 排列时某个窗口失败 | 逐个 `OperationResult` 记录，回总览后该行带 `!`，状态栏给失败计数 |
| 勾选的窗口被关掉 | 下一次刷新从选择里移除，状态栏说明"已关闭"（不是"移走"） |
| 列表为空 | 显示占位提示而不是空白 |
| 屏幕太窄放不下两列 | `computeLayout` 返回 false，状态栏说明宽度不足，停留在总览 |
| 平台命令未接入 | 明确说"等待 A 的接口"，绝不假装成功 |

## 动画（M4）

| 过渡 | 做法 | 时长 |
| --- | --- | --- |
| 打开总览 | `windowOpacity` 0→1，`OutCubic` | 170ms |
| 总览 ↔ 布局预览 | 页面整体淡出→换页→淡入 | 110 + 150ms |
| 收起总览 | 淡出后最小化（全局热键未接入时） | 140ms |

收起用"最小化"而不是"隐藏"：全局 `Ctrl+Alt+M` 由 A 注册，现在没有。真 `hide()` 会让窗口从任务栏消失且叫不回来，这正是交接文档警告的"操作后用户找不到窗口"。接入后加 `--allow-hide` 即可切成真隐藏。

## 手工测试步骤

```bat
build\crossdesk.exe --fake
```

1. 列表 4 行，含「设置」（系统窗口）。
2. 勾「未命名 - 记事本」→「定位」变亮；勾第二个 →「排列…」变亮。
3. 勾第三个 → 只有两个保持勾选，状态栏说"已替换"。
4. 点「排列…」→ 淡出淡入到预览页；切换「等宽 / 左侧主窗口 60/40」，左右两块宽度随之变化。
5. `Ctrl+Enter` → 回总览，状态栏"排列完成"，列表里的窗口位置已更新。
6. 只勾「设置」→ `Enter`（或点「定位」）→ 红字提示被系统拒绝，该行出现 `!`。
7. `Esc` 在预览页返回总览；在总览页收起（最小化到任务栏）。
8. 真实模式：`build\crossdesk.exe`（或 `run.bat`），能看到当前桌面的真实窗口，点「定位」会提示等待 A 的接口。

## 三个答辩追问题

1. **界面怎么知道窗口被关了？**
   下一次 `refresh()` 的快照里找不到这个 id。判断依据是"它在不在整份快照里"，不是"它从这一行消失了"。

2. **`layout_math.cpp` 为什么单独一个文件？**
   它属于 B 的职责（布局规则）。抽成无 Qt 依赖的纯函数后：能被单元测试直接调用、换 B 的实现只改这一处、界面不含任何比例常数。

3. **预览画布为什么不自己修正矩形？**
   画布只做"缩放 + 摆放"。如果比例不对，那是 B 的输入错了；界面偷偷修正会把问题藏起来，出问题时说不清是谁的责任。
