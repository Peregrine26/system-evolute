## 一句话

旧方案：把窗口分到几个 Workspace 里，切页整组换掉。
新方案：**一个列表 → 定位一个窗口 / 把两个窗口左右摆开 → 两段过渡动画 + 两个实时缩略图。**

多 Workspace、托盘、自动隐藏/恢复、Ubuntu X11 全部移出本学期范围。

| M4 动画 | 总览开合、总览 ↔ 布局预览 两段 | 无 | 能 |
| M5 快捷键 | 应用内 Ctrl+R / Enter / Ctrl+Enter / Esc；接收 A 的全局 Ctrl+Alt+M | 全局键由 A 注册 | 应用内能 |

## 界面结构（新）

```text
┌ 总览模式 ────────────────────────────────────────────┐
│ [刷新 Ctrl+R]   [定位 Enter]   [排列 Ctrl+Enter]      │
│ ┌ 列表（勾选框 / 标题 / 进程名）────┐  ┌ 布局预览 ──┐ │
│ │ ☐ 需求草稿.txt    notepad.exe    │  │ 等宽   ○   │ │
│ │ ☑ 项目资料       explorer.exe   │  │ 60:40  ●   │ │
│ │ ☑ 设置           SystemSettings │  │ ┌───┬───┐ │ │
│ └──────────────────────────────────┘  │ │ L │ R │ │ │
│  状态栏：成功 / 失败 / 替换提示        └────────────┘ │
└───────────────────────────────────────────────────────┘
```

- 两窗选择用**勾选框**，最多两个；勾第三个时替换最早勾的那个，并在状态栏说明。理由：答辩时用 Ctrl+点 容易点错，勾选框一眼能看出选了哪两个。
- 预览按 B 给的目标矩形画相对位置，不是真实像素截图；缩略图未接入时显示标题 + 进程名。
- 「确认排列」在未选满两个时不可用。

## 收起与唤回（M4 / M5 的坑）

M4 要求「收起总览」，M5 要求全局 `Ctrl+Alt+M` 打开。但全局热键由 A 注册，**当前不存在**。
若直接 `hide()`，窗口会从任务栏消失且无法再打开——正是交接文档警告的「操作后用户找不到窗口」。

策略：

- 全局热键**未接入**时：收起 = `showMinimized()`，任务栏图标保留，点它能回来；
- 全局热键**已接入**时：收起 = 真正 `hide()`，由 `Ctrl+Alt+M` 唤回；
- 启动参数 `--force-hide` 可强制真正隐藏，用于验证接入后的行为。

## 演示脚本（对着 `course-mvp.md` 走）

1. 开记事本、文件资源管理器、设置；
2. `Ctrl+Alt+M` 打开总览（未接入前双击 exe）；
3. 勾选记事本 + 资源管理器 → 选 60:40 → 预览出现左右两块；
4. `Ctrl+Enter` 确认，两个窗口左右排开；
5. `Esc` 回总览，只勾记事本按 `Enter` 定位；
6. 关掉记事本 → `Ctrl+R` → 条目消失。
