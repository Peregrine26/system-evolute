# CrossDesk 交互取舍

CrossDesk 的主操作是找到、定位和排列已打开的应用窗口；文件格子、待办、随记等工具帮助整理相关资料。两者共用一个进程和托盘，但保持各自的数据和可见性，不混用应用窗口与格子分组。

## 采用的规则

| 冲突点 | 最终采用的行为 | 原因 |
| --- | --- | --- |
| 启动与主入口 | 正常启动、再次启动和托盘“窗口总览”进入应用窗口总览；Ctrl+Alt+M 打开/收起同一总览。 | 主入口直接完成原来的窗口整理任务。 |
| 桌面工具与设置 | 总览里的“桌面工具”进入格子管理；托盘也保留此入口。两块主面板互相切换，`--desktop-tools` 可直接进入工具面板。 | 文件、待办、设置始终可达，又不会替换总览入口。 |
| 两窗排列 | 选择两个窗口 → 预览 → 确认排列；可以交换左右、切换 50:50/60:40，Esc 返回总览，再按 Esc 收起总览。 | 第一次进入预览不移动外部窗口，鼠标和键盘走相同操作。 |
| 确认时的变化 | 再检查句柄、PID、窗口边界及工作区；变化后要求重新预览，扫描不完整时不执行。提交和动画期间不重复执行。 | 用户确认的窗口及目标矩形应与实际请求一致。 |
| 关闭与退出 | 默认点主面板 X 后后台运行，保留格子、提醒和托盘；“退出 CrossDesk”才结束全部工具。允许关闭后台运行选项；无托盘时关闭主面板会退出。Esc 只收起面板。 | 兼顾常驻工具与明确退出，避免隐藏后失去入口。 |
| 编辑与保存失败 | 切换记录、新建随记、重建格子、恢复备份及退出前先保存；失败时保留编辑内容和窗口供重试。 | 切换界面不应丢失尚未保存的文字。 |
| F7 与格子关闭 | F7 临时隐藏/显示当前启用的格子，保留编辑器和持久化状态；单独关闭的格子不会被 F7 重开。“显示全部格子”或明确打开随记等操作可以重开。 | 临时收起和用户主动关闭具有不同含义。 |
| 快捷键 | 使用 RegisterHotKey，保留 F 键、Win 加按键或至少两个修饰键的组合；不拦截单独 Win、双击 Ctrl 或桌面点击。冲突不抢占已有组合，保留旧绑定，并在总览和工具面板显示状态。 | 系统和其他应用的常用输入继续有效。偏好设置可重试已保存的绑定。 |
| 屏幕变化 | 格子保存独立的原屏幕位置；断屏临时映射到剩余工作区，重新接回可回原位。只有主动拖动/缩放才认领新位置。适配时不重建编辑器。 | 临时断屏、分辨率变化不应破坏手工摆放及编辑状态。 |
| 外部窗口布局与多屏 | 外部应用排列继续使用平台提供的主显示器工作区；不随格子屏幕恢复自动移动应用窗口。 | Qt 逻辑坐标的格子恢复与 Win32 窗口排列是不同操作。 |
| 格子组与 Workspace | 格子保留标签分组、收起与悬停展开；不把它们当作外部应用 Workspace，不自动隐藏其他应用。 | 防止窗口归属和格子显示状态互相影响。 |
| 文件整理 | 保留分类预览、逐项目标和用户确认；不后台监视并搬走新文件。 | 文件位置变化应由用户明确发起，现有流程更容易解释和撤销。 |
| 备份恢复 | 提供“替换格子和记录”和“只合并待办随记”；两种方式都保留本机快捷键、启动、外观及资源设置。合并的 UUID 冲突另存副本，相同内容重复导入跳过。 | 恢复内容不应改变当前电脑的操作习惯和系统注册状态。 |
| 撤销历史 | 数据替换时清空文件移动撤销历史；合并记录时保留当前历史。 | 备份中的绝对路径可能属于另一台电脑或旧文件，不能据此撤销当前文件。 |
| 桌面层、云端与更新 | 保留独立 Qt 工具窗口和手动置顶、本地备份及现有 Git/PR 交付；本轮不接管 Explorer 层级、不自动配置 WebDAV 或运行升级安装器。 | 当前核心流程不需要依赖桌面壳层重启、远端账号和发布渠道。 |

开机启动仍是用户显式选择的选项，默认不开启。QuickLook、Everything 等外部程序集成继续排除。

## 验证

2026-11-25，本机通过 21 项 CTest。新增测试覆盖两阶段预览、失效身份/变化的窗口及工作区、不完整扫描、重复确认、主入口与工具导航、临时隐藏与明确关闭、存储失败时保留编辑器、格子断屏/重连和备份替换/合并。

实机窗口流程使用独立子进程创建两个测试窗口：预览前后边界一致，确认后两窗达到预览矩形，DWM 缩略图持续显示测试内容。测试只移动这些自建窗口。另一次主程序检查验证了默认启动和第二实例请求在两个主面板之间切换，同一工作区没有生成第二个常驻实例。

屏幕恢复逻辑使用模拟屏幕测试，尚未宣称完成所有真实显示器/DPI 组合验收。其他功能和运行方式见 [C++/Qt 桌面功能](qt-desktop-port.md)。
